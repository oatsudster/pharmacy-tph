💉 งานเบิกวัคซีน (EPI Routine · VMI อภ.)

นับสต็อก → รู้ว่า อภ. จะส่งกี่ขวด → พาทำทีละขั้นบนเว็บ scm.gpo.or.th

ระบบนี้ทำงานยังไง (อ่าน 2 นาที)

วัคซีน EPI Routine เป็นระบบ VMI คือ เราไม่ได้ "สั่ง" วัคซีนเอง เราแค่ บอกยอดคงเหลือ ให้ อภ. รู้ตามรอบ แล้ว อภ. คำนวณและส่งมาให้เอง

นับวัคซีนในตู้ (ขวด)→กรอกยอดบนเว็บ + SAVE→กด Post Inventory→อภ. ส่งวัคซีนมา→กด "รับยา" + PIN บนเว็บ↺

กติกาที่ อภ. ใช้คำนวณ (จากคู่มือ อภ. ก.พ. 2564):

  • ถ้า ยอดคงเหลือ (Onh รพ.) น้อยกว่า ROP → อภ. จะส่งให้
  • จำนวนที่ส่ง = MaxLimit − Onh แล้ว ปัดขึ้นให้เต็ม "ขนาดบรรจุ" (เช่น BCG ขนาดบรรจุ 100 dose = 10 ขวด) → ยอดหลังรับจึง เกิน MaxLimit ได้ แต่ไม่เกิน 1 ขนาดบรรจุ
  • ROP / MaxLimit / ขนาดบรรจุ เป็นค่าที่ อภ. กำหนด เรากรอกแค่ Onh (ขวด) ของแต่ละ Lot = ยอดคงเหลือจริง (ช่อง Onh (Dose) สีเทา เว็บคูณให้เอง)
  • ถ้ายอดคงเหลือ ≥ ROP → รอบนั้น ไม่ส่ง (ซึ่งเป็นเรื่องปกติ)
⚠️ ยังไม่ได้กด "รับยา" ใบนำส่งเก่า = บันทึก Inventory รอบใหม่ไม่ได้ ทุกครั้งที่ของมาถึง ต้องเข้าเว็บกดรับให้เสร็จ
⚠️ กดแค่ SAVE ยังไม่พอ ต้องกด Post Inventory ข้อมูลถึงจะส่งไปที่ อภ.

คำศัพท์บนหน้าเว็บ

ROP
ประมาณการใช้วัคซีนต่อเดือน (หน่วย dose) ที่ สปสช. อนุมัติให้ รพ. เป็นเกณฑ์ว่าจะส่งเมื่อไร
Onhand / Onh รพ.
ยอดคงเหลือในคลัง รพ. หน้าบันทึก Inventory กรอกช่อง Onh (ขวด) แยกตาม Lot แล้วเว็บคูณเป็น Onh (Dose) ให้ อภ. ใช้ค่า dose นี้คำนวณ
MaxLimit
เพดานที่ อภ. เติมให้ (≈ 1.5 × ROP)
ขนาดบรรจุ
หน่วยที่ อภ. ส่งต่อครั้ง (dose) ShipQty จะเป็นทวีคูณของค่านี้เสมอ
ShipQty
จำนวน dose ที่ อภ. จะส่งรอบนี้
บันทึก Inventory
เมนูกรอกยอดคงเหลือแยกตาม Lot
เพิ่ม Lot / Zero Onhand
ใช้เมื่อ Lot ในตู้ไม่ขึ้นในรายการ หรือวัคซีนตัวนั้นหมดเกลี้ยง (เลือก Zero Onhand)
Post Inventory
ปุ่มส่งข้อมูลจริง (ต้องกดหลัง SAVE)
ประวัติการบันทึกข้อมูล
ดูว่ารอบนี้ อภ. จะส่งอะไร (คอลัมน์ Ship Qty หน่วย dose) และช่วงวันที่จะส่ง
รับยา + PIN
ยืนยันว่าได้รับของตามใบนำส่งแล้ว (PIN ตั้ง/เปลี่ยนได้ที่ Setting)
เบิกวัคซีนเพิ่ม
ขอเพิ่มระหว่างรอบเมื่อของไม่พอ สปสช. อนุมัติวันถัดไป
FM3 EPI Routine
ขอปรับค่า ROP ถาวรเมื่อยอดใช้จริงเปลี่ยน
Download COA

ข้อมูลของ รพ.ถ้ำพรรณรา ที่หาเจอจากเว็บ อภ.

  • HCODE 11339 · VMI CODE 15800025 (จากไฟล์ "แผนกระจาย PCV (initial)" ของ อภ.)
  • PCV10 (ตัวใหม่ เริ่ม ต.ค. 69) อภ. ส่ง Initial Stock ให้อัตโนมัติ 15 ขวด (5 dose/ขวด) กำหนดถึง รพ. 20/10/69 ถ้าได้รับแล้วอย่าลืมกด "รับยา" และนับรวมในรอบถัดไป
  • JE เชื้อตาย เบิกพร้อมรอบปกติได้ แต่ให้เขียนในช่องหมายเหตุว่า เบิก JE เชื้อตาย จำนวน x ขวด (กันส่งสลับกับ JE เชื้อเป็น)
  • เข้าเว็บ: scm.gpo.or.th/vmi_next → Login ด้วย Username/Password ของ รพ. → โครงการ EPI1-วัคซีน EPI Routine (หมวด สปสช.)
  • ลืมรหัส / ผู้รับผิดชอบเปลี่ยน: เว็บ อภ. มี "ฟอร์มเปลี่ยนแปลงรายชื่อผู้รับผิดชอบโครงการ" ในหน้าข่าว EPI Routine
  • ติดต่อ อภ.: ระบบงาน/IT 02-203-8253 · กลุ่มงานบริหารผลิตภัณฑ์ 02-203-8908-9
  • คู่มือเต็มของ อภ.: คู่มือการเบิกวัคซีน Routine (ก.พ. 2564)

หน้านี้ไม่เก็บ Username/Password ของ รพ. · ยอดสต็อก/ประวัติ ซิงค์ผ่านฐานข้อมูลกลางของเว็บห้องยา (เปิดเครื่องไหนก็เห็นข้อมูลเดียวกัน) และสำรองเป็นไฟล์ได้ที่แท็บ ⑤

⚡ คำนวณด่วน: เลือกยอดที่อยากให้ อภ. ส่ง → ต้องกรอก Onh เท่าไร

เลือกยอดที่ต้องการให้ อภ. ส่ง (มีให้เลือกเฉพาะยอดที่ อภ. ส่งได้จริง = ทวีคูณของขนาดบรรจุ) → โปรแกรมหาค่า Onh (ขวด) ที่ทำให้สูตร อภ. ส่งตามนั้น (ใช้ค่าที่สูงที่สุดที่ยังได้ยอดนี้ = ใกล้ยอดจริงที่สุด) · สูตร อภ.: ถ้า Onh < ROP → ส่ง = ปัดขึ้น(MaxLimit − Onh) ให้เต็มขนาดบรรจุ · ถ้า Onh ≥ ROP → ไม่ส่ง · อภ. ส่งเป็นทวีคูณของขนาดบรรจุ และเติมจนถึง MaxLimit ทุกครั้งที่ส่ง → ขอน้อยกว่า "สูตรส่งได้" ขั้นต่ำไม่ได้ (จะได้ขั้นต่ำนั้นแทน)

บนเว็บ (หน้า บันทึก Inventory) กรอกช่อง Onh (ขวด) ตามคอลัมน์สีเขียว (ถ้ามีหลาย Lot ให้ผลรวมทุก Lot เท่ากับตัวเลขนี้) · ช่อง Onh (Dose) สีเทาเว็บคิดเอง ต้องได้เท่ากับคอลัมน์ "Onh (Dose)" ในตารางนี้ · ถ้าตัวเลขต่างจากยอดที่นับได้จริงมาก (เช่นต้องการมากกว่าที่สูตรส่งได้) ใช้ ④ เบิกเพิ่ม / FM3 ปรับ ROP แทน
