HOSxP Bridge (ไม่ใช้ exe)

วิธีติดตั้ง
1. แตก zip ให้เสร็จก่อน ไปไว้ในโฟลเดอร์ในเครื่อง เช่น C:\HxpSetup (อย่ารันจากในหน้าต่าง zip)
   ถ้า Windows เตือนว่าไฟล์มาจากอินเทอร์เน็ต: คลิกขวาไฟล์ zip > Properties > ติ๊ก Unblock ก่อนแตกไฟล์
2. ดับเบิลคลิก install.cmd
3. เลือกวันที่ให้เปิดเอง: Yes = เฉพาะพุธ-พฤหัส, No = ทุกวัน
4. ในหน้าตั้งค่าเบราว์เซอร์ที่เปิดขึ้น ตั้ง "Local network" และ "Apps on device" เป็น Allow

ไม่อยากแตก zip: เปิดหน้าเว็บ (เช่นหน้าคลินิก) จะมีปุ่ม "คัดลอกคำสั่งติดตั้ง" → กด Win+R → Ctrl+V → Enter ติดตั้งจากเว็บได้เลย
ถ้า install.cmd ใช้ไม่ได้: คลิกขวา install.ps1 > Run with PowerShell
หรือไม่ติดตั้งเลย: คัดลอก hosxp-bridge.ps1, hxdb.cs, db.json กับ start-bridge.bat ไปไว้ในโฟลเดอร์เดียวกัน แล้วดับเบิลคลิก start-bridge.bat

อัปเดต: ติดตั้งครั้งนี้ครั้งสุดท้าย — ต่อไปเมื่อเปิดหน้าเว็บ (เช่นหน้าคลินิก) แล้วพบว่า bridge เป็นรุ่นเก่า หน้าเว็บจะสั่งอัปเดตให้เองอัตโนมัติ
  (ดาวน์โหลดไฟล์ใหม่ สำรองของเดิมไว้ในโฟลเดอร์ backup ถ้าตัวใหม่เปิดไม่ขึ้นจะคืนตัวเดิมให้เอง)

Bridge ทำงานเบื้องหลัง ไม่มีหน้าต่างบน taskbar
  ปิด: ดับเบิลคลิก stop-bridge.bat / เปิดใหม่หรือรีสตาร์ท: ดับเบิลคลิก start-bridge.bat (ในโฟลเดอร์ %LOCALAPPDATA%\HOSxPBridge)

ถอนการติดตั้ง: ดับเบิลคลิก uninstall.cmd ในโฟลเดอร์ %LOCALAPPDATA%\HOSxPBridge

ฐานข้อมูล HOSxP
ชุดนี้มี db.json (รหัสฐานข้อมูล HOSxP แบบอ่านอย่างเดียว) — bridge จะอ่านใบสั่งยา วันนัด และยาของ visit ก่อนๆ จากฐานข้อมูลแทนการอ่านหน้าจอ (OCR)
ถ้าต่อฐานข้อมูลไม่ได้ จะกลับไปใช้ OCR เองอัตโนมัติ
ห้ามส่งไฟล์ zip นี้ออกนอกเครือข่ายโรงพยาบาล (มีรหัสฐานข้อมูลอยู่ข้างใน)
